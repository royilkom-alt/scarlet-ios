## What Is Scarlet?

Scarlet is an iOS application that can be used to import, sign, manage, and install compatible IPA files on an iPhone or iPad.

Scarlet may provide features such as:

* IPA file importing
* On-device IPA signing
* Direct app installation
* Certificate importing
* Application management
* Bundle identifier customization
* App name customization

Available features may depend on the installed Scarlet version, certificate type, provisioning profile, and iOS version.

---

## Scarlet Installation Methods

Scarlet may be installed using one of the following methods:

| Method               | Description                                                                          |
| -------------------- | ------------------------------------------------------------------------------------ |
| Direct Install       | Installs Scarlet directly through Safari using an available enterprise certificate   |
| Certificate Signing  | Signs the Scarlet IPA using a compatible `.p12` certificate and provisioning profile |
| Computer Sideloading | Installs Scarlet using a computer-based sideloading application                      |
| Personal Apple ID    | Signs Scarlet using a personal Apple ID certificate                                  |

The simplest method is normally **Direct Install**, but it depends on whether an active certificate is currently available.

### Certificate Installation

A Scarlet certificate package may include:

```text
Certificate.p12
Certificate.mobileprovision
Password.txt
```

The certificate, provisioning profile, and password must come from the same package.

Do not combine files from different certificate packages because mismatched files can cause signing or installation errors.

## How to Trust Scarlet

After Scarlet has been installed:

1. Open the **Settings** app.
2. Go to **General**.
3. Open **VPN & Device Management**.
4. Select the enterprise developer profile used to install Scarlet.
5. Tap **Trust** or **Verify App**.
6. Confirm the action.
7. Return to the Home Screen.
8. Open Scarlet.

Menu wording may vary depending on the installed iOS version.

```text
Settings → General → VPN & Device Management
```

> [!NOTE]
> If the developer profile cannot be verified, the certificate may have expired or been revoked.

## How to Install IPA Files with Scarlet

After Scarlet opens successfully:

1. Download an IPA file from a source you trust.
2. Open Scarlet.
3. Tap the import or download button.

5. Wait for Scarlet to import the application.
6. Select the imported app.
7. Choose the available signing or installation option.
8. Wait for the process to complete.
9. Confirm the iOS installation prompt.
10. Return to the Home Screen and wait for the app to install.

Only install applications you trust, own, or have permission to use.

## Scarlet Certificate Files

A compatible certificate package normally contains:

| File               | Purpose                                                  |
| ------------------ | -------------------------------------------------------- |
| `.p12`             | Contains the signing certificate and private key         |
| `.mobileprovision` | Contains the provisioning profile                        |
| Password file      | Contains the password required to import the certificate |

Common password filenames include:

```text
Password.txt
password.txt
cert.txt
README.txt
Certificate Password.txt
```

### Certificate Password Not Working

Check the following:

* Remove spaces before or after the password.
* Check uppercase and lowercase characters.
* Confirm the password belongs to the selected `.p12` file.
* Make sure the downloaded ZIP file was extracted completely.
* Do not use a password from another certificate package.
* Download the original package again when necessary.

## Troubleshooting

### Scarlet Is Not Installing

Possible causes include:

* The certificate has been revoked.
* The certificate has expired.
* The provisioning profile is no longer valid.
* Another version of Scarlet is already installed.
* The device cannot connect to the installation server.
* The installation link is temporarily unavailable.

Possible solutions:

1. Delete the existing Scarlet installation.
2. Restart the iPhone or iPad.
3. Open AppleJR again in Safari.
4. Choose another available Scarlet installation option.
5. Confirm that the device has a stable internet connection.
6. Try the installation again.

---

### Unable to Install Scarlet

The **Unable to Install** message may indicate that the selected certificate is no longer accepted.

Delete the failed Scarlet icon and try another currently available certificate from AppleJR.

### Integrity Could Not Be Verified

This message commonly appears when:

* The certificate has been revoked.
* The provisioning profile has expired.
* The app signature is no longer accepted.
* The certificate and provisioning profile do not match.

Return to AppleJR and select another available Scarlet installation option.

---

### Unable to Verify App

Open:

```text
Settings → General → VPN & Device Management
```

Select the developer profile and check whether **Trust** or **Verify App** is available.

If verification continues to fail, the certificate may no longer be active.

---

### Untrusted Enterprise Developer

Open:

```text
Settings → General → VPN & Device Management
```

Select the enterprise developer profile and tap the available trust option.

After trusting the profile, reopen Scarlet.

---

### Scarlet Opens and Immediately Closes

Possible causes include:

* Certificate revocation
* Expired provisioning profile
* Incompatible Scarlet build
* Unsupported application entitlements
* Incorrect signing configuration
* Incomplete app installation

Delete Scarlet and install a fresh version using another available method.

---

### Scarlet Certificate Import Failed

Make sure that:

* The `.p12` file is not corrupted.
* The certificate password is correct.
* The certificate package has been extracted.
* The `.mobileprovision` file matches the certificate.
* Files from different certificate packages were not mixed.
* The certificate has not expired.

---

### Scarlet Cannot Install an IPA

An IPA may fail to install when:

* The IPA file is corrupted.
* The application requires unsupported entitlements.
* The bundle identifier conflicts with another installed app.
* The certificate has reached its device limit.
* The application does not support the installed iOS version.
* The app was not signed correctly.

Try using a clean IPA file from a trusted source and sign it again.
